# Deep24 Idea Lab

A proof-of-work prototype exploring a pre-build requirements layer for Deep24: users describe an app idea in plain English, then the system asks intelligent follow-up questions before producing a structured build specification.

## Current slice

Screen 1 only:
- App idea textarea
- Clickable starter examples
- Disabled state until an idea is entered
- Loading state: "Understanding your idea..."
- Temporary preview of the next step

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
